Home HQ Calendar Sync Privacy Policy

This policy covers the standalone Home HQ Calendar Sync integration, not other Home HQ features or separate assistant-assisted workflows.

Access and use

The integration requests only Google Calendar availability access: https://www.googleapis.com/auth/calendar.events.freebusy. This permission supports availability queries for calendars the authorizing account can access. The integration queries only the configured calendar for busy start and end times, to display “Busy” blocks on the owner’s frame.

It does not request meeting titles, descriptions, locations, or attendees, and it does not edit calendars.

Storage and sharing

The calendar identifier, OAuth client configuration, and authorization tokens are stored on the owner’s sync computer. Credential files require owner-only file permissions. Google processes authorization and availability requests.

The integration transfers a busy-only snapshot to the owner’s frame, which also caches it for display. The snapshot includes busy times, coverage dates, a refresh timestamp, and display metadata—not OAuth credentials.

Calendar data is not published on this website, sold, used for advertising, or used to train artificial intelligence models. The standalone sync does not send it to an AI service.

Retention and control

The latest successful snapshot remains until replaced or deleted. Failed updates preserve the last successful snapshot; stale data is marked, not automatically erased.

To stop access, disable scheduled sync and revoke the application in Google Account’s third-party connections settings. Revocation does not erase existing copies. The owner can delete local credentials and remove the frame’s snapshot and dashboard cache.

Google API data

Home HQ Calendar Sync’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions and deletion assistance

Contact the project maintainer through GitHub Issues. Issues are public: do not include credentials, tokens, calendar identifiers, calendar details, or other private information.
