Personal Home Assistant / Nest Privacy Policy

This policy covers this owner-operated Home Assistant integration with Google Nest, not the separate calendar integration or all Home Assistant installations.

Data accessed and purpose

Depending on the authorized devices and features, the integration can process device and room identifiers, names, status information, event types and timestamps, live camera streams, and supported event images or clips. Thermostat data can include temperature, humidity, heating or cooling state, operating mode, target temperatures, and fan status or timer settings. These support personal camera viewing, climate monitoring, and owner-configured home automation.

Where authorized and supported, owner requests or owner-configured automations can send thermostat commands through Google, such as changing modes, target temperatures, or fan timers. Google controls access according to the permissions approved by the owner. This device integration supports controls; it is not the separate availability-only calendar application.

Storage and processing

Connection configuration and authorization tokens are maintained by the owner’s Home Assistant installation. Google services process authentication, device access and control, streaming, and event delivery. Authorized dashboards and displays receive the information needed for their features.

Home Assistant can save supported event media locally. It may also retain device history, logs, and media created by configured features. Retention depends on those features, storage policies, and backups; there is no promise of zero recording or a single automatic deletion period.

Owner-enabled notification, remote-access, automation, and backup services may additionally process data according to their configuration. This personal integration does not sell Google user data or use it for advertising. Nest device data and credentials are not published on this informational website.

Control and deletion

The owner can disconnect access through Google Partner Connections Manager and remove the Nest integration from Home Assistant.

Disconnecting does not erase previously saved media, history, logs, exports, or backups; those copies must be removed through their respective storage controls. Google/Nest cloud history is managed separately.

Google API data

This personal integration’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Questions and deletion assistance

Contact the project maintainer through GitHub Issues. Issues are public: do not include credentials, tokens, private identifiers, addresses, camera media, or other private information.
